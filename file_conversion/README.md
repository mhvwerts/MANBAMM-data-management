# Conversion of proprietary instrument file formats into open formats

The data-files generated by many scientific instruments (e.g. spectrometers) often cannot be read directly by data analysis software, since they are recorded in formats designed by the instrument manufacturer. These proprietary file formats are rarely openly documented. For ensuring long-term and broad accessibility of open scientific data, the files need to be converted to and stored in an open format (CSV, HDF5, TIFF, etc.)

Over the years, we have programmed several 'file loaders' in Python that read instrument data in proprietary formats. Our aim is to present these Python file-reader routines here, after careful checking and necessary clean-up of the code. The file-reader routines can then be used for converting (sets of) instrument data files into files in an easily accessible, open format.
